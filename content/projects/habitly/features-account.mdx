One provider owns the account lifecycle. Signing in switches the database
owner, which swaps the SQLite file; brand-new cloud accounts import the
guest data once. Deletion requires a fresh sign-in, stops sync, clears the
server data through the trusted endpoint, wipes the local file, and returns
the app to onboarding.
