title: Run locally
description: Install, start, and open on device.
sources:

---

```bash
pnpm install
pnpm start
```

Open the project in an Android development build or Expo Go. The app
targets Android and web; iOS is not configured. Local records persist
between launches, and the first launch seeds sample habits and tasks.

Last verified 2026-10-11. This project makes no claim about any store
listing — none is documented in the repo.
