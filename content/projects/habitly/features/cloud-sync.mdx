Only what the code implements: Google sign-in (native on device, popup on
web), per-account SQLite files, an outbox that uploads before any pull,
listeners that restore other devices' edits, and deletion that demands a
fresh sign-in and server confirmation. Same-record conflicts resolve in
the order Firestore accepts writes. None of this runs without Firebase
values and a proper build — otherwise the app stays a guest.
