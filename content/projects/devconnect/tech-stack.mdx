Every library below is declared in some workspace manifest — names, version
ranges, and categories come from the data, and the build fails if the list
drifts. "Used in" points at the folders that import each library. Libraries
marked "Declared but not used in source" sit in a manifest but no source file
imports them — most notably better-auth, which both manifests declare while
authentication actually runs on JWT plus bcrypt.
