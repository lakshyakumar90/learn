Profiles mix hand-written fields with synced GitHub data (stats, top repos,
skills derived from repo languages). Avatar and cover uploads ride the
same Multer-plus-Cloudinary path as post images, with a local fallback.
Discovery has two doors: the paged user feed (excluding the user and their
connections) and name-or-skill search.
