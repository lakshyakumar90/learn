Posts carry text, an optional image URL, a code snippet with language, a
type, tags, and a collaboration flag. The recent tab pages by cursor; the
top tab aggregates like counts over the last week. Code snippets render
with syntax highlighting in the post card. Likes and comments both notify
the post author.
