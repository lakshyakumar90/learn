Authentication is JWT plus bcrypt — `better-auth` sits in both manifests
but no source file imports it. Email users register and log in through the
user controller with 30-day tokens; GitHub users arrive through OAuth and
get the same token. The guard reads the cookie first and the Bearer header
second, which keeps hosted frontends working. One honest gap: the signup
page reads a `fulfilled` matcher off a plain thunk, so its post-submit
redirect is unverified — login and session restore follow the same token
path and are straightforward.
