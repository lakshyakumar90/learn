The entry requires the database connector (which connects on import),
declares permissive CORS with credentials, serves `uploads/` statically,
answers `/health` and `/api/health` without auth or DB waits, mounts the
API routers, hands the HTTP server to the socket initializer, and listens
on `PORT`. `trust proxy` is set for rate limiting behind a proxy.
