One file owns realtime end to end. Sockets register a user id and join that
id as a room, so any process can reach a user by id once the Redis adapter
is attached. Presence is tracked twice: a local socket map for instant
lookups and a Redis hash so other instances agree. Typing and status
broadcasts are never stored; messages always are, with sent, delivered, and
read states.
