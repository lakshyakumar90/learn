Every REST module builds on `createApi`, so the Bearer token, the 30-second
timeout, and the expired-session event behave the same everywhere. Base URLs
come from `VITE_API_URL` with localhost fallbacks; the socket URL prefers
`VITE_SOCKET_URL`, then derives from the API URL. The socket service maps
server events straight into slice actions.
