The system splits across four hosts. The browser loads the web app from Vercel,
then talks to an HTTP service and a WebSocket service on Render, which read and
write Neon Postgres and Upstash Redis. A Render flush worker moves room snapshots
from Redis into Postgres.

| Service | Host | Cost |
| --- | --- | --- |
| Web app | Vercel | Free |
| HTTP service | Render web service | Free, sleeps when idle |
| WebSocket service | Render web service | Free, sleeps when idle |
| Flush worker | Render | Paid (needs to run continuously) |
| Postgres | Neon | Free tier |
| Redis | Upstash | Free tier |

Free means limited: Render sleeps idle web services and rations instance hours,
Neon and Upstash cap their free tiers. Nothing here is production-grade, and every
limit below can change — re-check the linked docs before you rely on a number.

Last verified: 2026-10-11.
