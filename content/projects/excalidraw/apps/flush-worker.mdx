The worker reads each dirty snapshot, inserts a new scene revision only when the
database is behind, and retains the latest revisions. It touches nothing live:
presence and previews never pass through here, so a room can be busy without ever
being flushed mid-thought — the debounce decides when a snapshot is durable.
