Each service lists its workspace dependencies in its own `package.json`; the diagram
shows the main ones. The web editor imports the engine, the shared models, and auth.
The HTTP and WebSocket servers share the backend collaboration helpers, and both
reach the database and Redis packages. The flush worker touches only Redis and the
database.
