<Tabs items={['Vercel (primary)', 'Cloudflare (alternative)']}>
<Tab value="Vercel (primary)">
Deploy the web app on Vercel. Set `NEXT_PUBLIC_API_URL` to the public HTTP
service URL and `NEXT_PUBLIC_WS_URL` to the public WebSocket URL — both are
baked in at build time, so changing them needs a redeploy. Keep
`NEXT_PUBLIC_GOOGLE_AUTH_ENABLED` as `false` unless Google OAuth is configured.
</Tab>
<Tab value="Cloudflare (alternative)">
The frontend can alternatively run on Cloudflare Workers through the OpenNext
adapter. Read Cloudflare's current Next.js guide first — it may recommend a
different adapter for new apps — and treat this app as untested there until
someone verifies sign-in, rooms, and presence against it.
</Tab>
</Tabs>

Last verified: 2026-10-11. Free-tier limits change — check the providers before
