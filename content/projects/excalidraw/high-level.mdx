The browser holds the editor, a sync outbox, and IndexedDB. Signed-in saves travel
through the HTTP server into Postgres. Room work travels through the WebSocket
server into Redis, and the flush worker later writes durable snapshots from Redis
back into Postgres.

Solid lines are durable data — committed elements and database rows. Dashed lines
are ephemeral — presence, previews, and other live state that is never stored.
