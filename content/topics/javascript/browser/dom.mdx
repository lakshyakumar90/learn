{`function makeTodoStore() {
  let todos = [];
  return {
    add(text) {
      const clean = text.trim();
      if (!clean) return false;
      todos = [...todos, { id: todos.length + 1, text: clean }];
      return true;
    },
    list() {
      return todos.map((todo) => ({ ...todo }));
    },
  };
}
const store = makeTodoStore();
console.log(store.add(" buy tea "));
console.log(store.add(""));
console.log(store.list()[0].text);
console.log("count", store.list().length);
const contractChecks = [
  store.list().length === 1,
  store.list()[0].text === "buy tea",
];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}
</CodeRunner>

const list = document.querySelector("#list");
function addItem() {
  const text = input.value.trim();
  if (!text) return;
  const row = document.createElement("li");
  row.textContent = text;
  list.append(row);
  input.value = "";
  document.querySelector("#status").textContent =
    "Items: " + list.children.length;
}
document.querySelector("#add").addEventListener("click", addItem);
input.addEventListener("keydown", (event) => {
  if (event.key === "Enter") addItem();
});
console.log("textContent keeps markup inert");`}
</CodeRunner>

## Why it works this way

Separate model tests from rendering checks. TextContent keeps markup inert; trusted rich HTML requires a maintained sanitizer.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>

- The browser owns DOM nodes and their lifecycle.
- Separate model tests from rendering checks.
