# JavaScript illustration style

Flat vector illustration with soft rounded shapes, subtle offset shadows and generous whitespace. Use warm neutral #faf9f7 backgrounds, indigo #4f46e5, teal #0d9488, amber #d97706 and violet #7c3aed from the site's CSS tokens. A recurring fictional person wears an indigo sweater and uses a rounded cream laptop; objects stay consistent across scenes. Keep the composition simple, friendly and spacious, without decorative UI. No text, letters, numbers, logos, trademarks, real faces, code, terminal output, software screenshots or data charts.

Every prompt starts with the paragraph above. Artwork communicates everyday context or an explicitly labelled analogy. Exact execution, queue order, scope and reachability stay in code-driven diagrams. Dark versions use #1c1917 backgrounds and #a5b4fc / #5eead4 / #fbbf24 accents. HTML supplies captions and accessible transcripts. Landscape assets use a 4:3 or 16:9 frame, maximum 1600px wide, WebP and 150 KB.

Character consistency: flagship scenes use the cover learner with shoulder-length wavy dark hair. Object-only metaphors avoid introducing another character. The first overwhelmed learner and original standing-cart character were discarded after the small test set.
