## Terms in context

A binding connects a name to a value; a closure retains access to surrounding bindings. A prototype supplies fallback properties, while an iterator supplies values on demand.

Tasks run to completion and microtasks run at checkpoints. Rendering opportunities may produce frames; promise completion does not move CPU work to a background thread.
