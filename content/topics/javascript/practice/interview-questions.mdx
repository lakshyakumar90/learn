## How it works

### Build the working version

<CodeRunner title="Build: Interview-style questions" expect="ready cart\nready cart\ncalls 1\ncontract true">
{`function once(operation) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      result = operation(...args);
      called = true;
    }
    return result;
  };
}
let calls = 0;
const initialize = once((name) => {
  calls++;
  return "ready " + name;
});
console.log(initialize("cart"));
console.log(initialize("search"));
console.log("calls", calls);
const contractChecks = [calls === 1, initialize("again") === "ready cart"];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}
</CodeRunner>

The console runner is an isolated browser worker. These core examples are also checked in Node; DOM behavior belongs to the browser frame, and fakeFetch is sample data rather than a real network request.

## Why it works this way

This once retries a thrown call but caches a returned rejected promise. Explain that policy and use a state machine when async retry behavior matters.
