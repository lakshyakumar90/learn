## Make the trade-off explicit

A shared language can reduce translation between browser and server. It does not give them the same APIs, permissions or deployment behavior.

Dynamic inputs make iteration easy but require boundary validation. TypeScript checks declared types; it does not make arbitrary network JSON trustworthy.

For CPU-heavy reports, measure realistic data before choosing workers or another service. For ordinary forms and API clients, keep the implementation small and test user-visible behavior.
