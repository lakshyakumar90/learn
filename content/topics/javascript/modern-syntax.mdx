Modern syntax removes ceremony: names for the pieces, safe deep access,
sane defaults. Interviewers ask this to check you write current JavaScript —
and know which sugar hides real behavior (shared references, silent
`undefined`).

## Real-life situation

A settings screen merges saved preferences over defaults, reads an
optional support email, and totals a variable list of fees. Spread merges
one level, `?.` short-circuits the missing contact, `??` keeps a real zero
page number, and rest gathers the fees — four features, zero helper
functions.

## ES modules versus CommonJS, in short

ES modules use static `import`/`export` that bundlers analyze and
tree-shake; one file, one scope, always strict. CommonJS uses runtime
`require`/`module.exports` — flexible but opaque. Browsers speak ESM; Node
reads both and picks by extension and `package.json` type.

```js
import { total } from "./cart.js";
```

## Key takeaways

- Destructure for names, spread to expand, rest to gather.
- `?.` short-circuits missing links; `??` defaults only nullish values.
- ESM is static and shakable; CommonJS is dynamic and opaque.
