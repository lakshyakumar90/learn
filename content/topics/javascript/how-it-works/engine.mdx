## How it works

### Build the working version

<CodeRunner title="Build: The engine" expect="rows 1000\ntotal 2000\nupdated 4000\noriginal 2000\ncontract true">
{`function makeRow(id, price) {
  return { id, price, quantity: 1 };
}
function total(rows) {
  let value = 0;
  for (const row of rows) value += row.price * row.quantity;
  return value;
}
const rows = Array.from({ length: 1000 }, (_, index) => {
  return makeRow(index, 2);
});
console.log("rows", rows.length);
console.log("total", total(rows));
const updated = rows.map((row) => ({ ...row, quantity: 2 }));
console.log("updated", total(updated));
console.log("original", total(rows));
const contractChecks = [total(rows) === 2000, total(updated) === 4000];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}
</CodeRunner>

The console runner is an isolated browser worker. These core examples are also checked in Node; DOM behavior belongs to the browser frame, and fakeFetch is sample data rather than a real network request.

## Why it works this way

Measure representative workloads. Engine versions, warm-up and data can change which implementation is faster.
