## How it works

### Build the working version

<CodeRunner title="Build: Streams" expect="tea,rice,coffee\nchunks 3">
{`const chunks = ["tea,", "rice,", "coffee"];
const source = new ReadableStream({
  start(controller) {
    for (const chunk of chunks) controller.enqueue(chunk);
    controller.close();
  },
});
const reader = source.getReader();
let report = "";
try {
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    report += value;
  }
} finally {
  reader.releaseLock();
}
console.log(report);
console.log("chunks", chunks.length);`}
</CodeRunner>

The console runner is an isolated browser worker. These core examples are also checked in Node; DOM behavior belongs to the browser frame, and fakeFetch is sample data rather than a real network request.

## Why it works this way

Chunks need not align with records or characters. Decode incrementally, buffer incomplete records and cancel abandoned readers.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
