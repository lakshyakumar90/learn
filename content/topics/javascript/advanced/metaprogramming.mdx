### Find its limit

A shallow copy shares nested data. Change the input and predict the output before you run it. The failure comes from a specific default, lifetime or ownership assumption; keep that assumption visible in the test.

### Build the working version

<CodeRunner title="Build: Metaprogramming" expect="tea\nRICE\nunknown action\ncontract true">
{`function exposeActions(actions) {
  const allowed = new Set(Object.keys(actions));
  return {
    call(name, value) {
      if (!allowed.has(name)) return "unknown action";
      const action = Reflect.get(actions, name);
      if (typeof action !== "function") return "not callable";
      return Reflect.apply(action, undefined, [value]);
    },
  };
}
const toolbar = exposeActions({
  trim: (value) => value.trim(),
  upper: (value) => value.toUpperCase(),
});
console.log(toolbar.call("trim", " tea "));
console.log(toolbar.call("upper", "rice"));
console.log(toolbar.call("__proto__", "ignored"));
const contractChecks = [
  toolbar.call("__proto__", "") === "unknown action",
  toolbar.call("upper", "tea") === "TEA",
];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}
</CodeRunner>

The console runner is an isolated browser worker. These core examples are also checked in Node; DOM behavior belongs to the browser frame, and fakeFetch is sample data rather than a real network request.

## Why it works this way

Reflection can hide dependencies. Keep action maps narrow and never turn external strings into eval input.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>

## Mistakes that reach production

### A shallow copy shares nested data

Run the reproduction, then the corrected version. Compare the value at the boundary; the fix changes the cause rather than hiding the symptom.

<CodeRunner title="Bug: A shallow copy shares nested data" expect="Delhi">
{`const account = { address: { city: "Pune" } };
const edited = { ...account };
edited.address.city = "Delhi";
console.log(account.address.city);`}
</CodeRunner>

<CodeRunner title="Fix: A shallow copy shares nested data" expect="Pune">
{`const account = { address: { city: "Pune" } };
const edited = { ...account, address: { ...account.address } };
edited.address.city = "Delhi";
console.log(account.address.city);`}
</CodeRunner>

### Inherited names pass a naive membership test

Run the reproduction, then the corrected version. Compare the value at the boundary; the fix changes the cause rather than hiding the symptom.

<CodeRunner title="Bug: Inherited names pass a naive membership test" expect="true">
{`const actions = { save: true };
const accepted = "toString" in actions;
console.log(accepted);`}
</CodeRunner>

<CodeRunner title="Fix: Inherited names pass a naive membership test" expect="false">
{`const actions = { save: true };
const accepted = Object.hasOwn(actions, "toString");
console.log(accepted);`}
</CodeRunner>
