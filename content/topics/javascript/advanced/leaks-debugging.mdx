### Build the working version

<CodeRunner title="Build: Memory leaks and debugging" expect="cart 12\nbefore cleanup 1\nafter cleanup 0">
{`function makeEventBus() {
  const listeners = new Set();
  return {
    subscribe(listener) {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },
    publish(value) {
      for (const listener of listeners) listener(value);
    },
    count() {
      return listeners.size;
    },
  };
}
const bus = makeEventBus();
const release = bus.subscribe((total) => console.log("cart", total));
bus.publish(12);
console.log("before cleanup", bus.count());
release();
bus.publish(18);
console.log("after cleanup", bus.count());`}
</CodeRunner>

The console runner is an isolated browser worker. These core examples are also checked in Node; DOM behavior belongs to the browser frame, and fakeFetch is sample data rather than a real network request.

## Why it works this way

Cleanup belongs to the subscription lifecycle. Listener counts show retention, not heap sizes; collection timing is not asserted.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>

## Mistakes that reach production

### Subscriptions accumulate across mounts

Run the reproduction, then the corrected version. Compare the value at the boundary; the fix changes the cause rather than hiding the symptom.

<CodeRunner title="Bug: Subscriptions accumulate across mounts" expect="1">

</CodeRunner>

<CodeRunner title="Fix: Subscriptions accumulate across mounts" expect="0">
{`const listeners = new Set();
const handler = () => 12;
listeners.add(handler);
listeners.delete(handler);
console.log(listeners.size);`}
</CodeRunner>

### An unbounded cache retains every search

Run the reproduction, then the corrected version. Compare the value at the boundary; the fix changes the cause rather than hiding the symptom.

<CodeRunner title="Bug: An unbounded cache retains every search" expect="3">
{`const cache = new Map();
for (const query of ["tea", "rice", "coffee"]) cache.set(query, {});
console.log(cache.size);`}
</CodeRunner>

<CodeRunner title="Fix: An unbounded cache retains every search" expect="2">
{`const cache = new Map();
for (const query of ["tea", "rice", "coffee"]) {
  cache.set(query, {});
  if (cache.size > 2) cache.delete(cache.keys().next().value);
}
console.log(cache.size);`}
</CodeRunner>

- A listener is reachable through its target until removed.
- Cleanup belongs to the subscription lifecycle.
