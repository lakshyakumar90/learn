## How it works

<Diagram id="js-types" />

Nullish coalescing preserves zero and empty strings. Optional access stops at a missing link but does not validate the final type.

{`const incoming = {
  customer: { name: "Meera" },
  discount: 0,
  items: [{ name: "tea", quantity: 2 }],

function summarize(order) {
  const name = order.customer?.name ?? "Guest";
  const discount = order.discount ?? 10;
  const items = order.items ?? [];
  const sorted = [...items].sort((first, second) => {
    return first.name.localeCompare(second.name);
  });
  return { name, discount, count: sorted.length };
}
console.log(summarize(incoming).name);
console.log("zero discount", summarize(incoming).discount);
console.log("guest", summarize({}).name);
console.log("items", summarize(incoming).count);
const contractChecks = [
  summarize({}).name === "Guest",
  summarize(incoming).discount === 0,
];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}

## Why it works this way

These examples avoid proposal-specific APIs. Check target engine support before adopting newer features rather than guessing availability.
