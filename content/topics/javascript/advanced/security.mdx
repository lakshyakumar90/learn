{`const unsafe = JSON.parse('{"__proto__":{"admin":true},"name":"Meera"}');
function safeProfile(input) {
  const profile = Object.create(null);
  for (const key of ["name", "city"]) {
    if (typeof input[key] === "string") profile[key] = input[key];
  }
  return profile;
}
const profile = safeProfile(unsafe);
console.log("name", profile.name);
console.log("admin absent", profile.admin === undefined);
console.log("no inherited prototype", Object.getPrototypeOf(profile) === null);
const userText = '<img src=x onerror="alert(1)">';
function textPreview(value) {
  return value.replaceAll("<", "&lt;").replaceAll(">", "&gt;");
}
console.log("preview", textPreview(userText));
console.log("in DOM use textContent, not this partial escape");
const contractChecks = [
  !Object.hasOwn(profile, "__proto__"),
  profile.admin === undefined,

if (!contractChecks.every(Boolean)) {

}
console.log("contract", contractChecks.every(Boolean));`}

## Why it works this way

Partial escaping is not sanitization. Rich HTML needs a maintained sanitizer and validation; a real CSP header belongs to the hosting server.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>

### An action name accesses an inherited member
