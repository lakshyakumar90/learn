## Why it works this way

Use stable ID strings when records should merge. WeakMap fits object metadata without strong key retention; symbols do not make secrets.

Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.

## Mistakes that reach production

### A shallow copy shares nested data

Run the reproduction, then the corrected version. Compare the value at the boundary; the fix changes the cause rather than hiding the symptom.

<CodeRunner title="Bug: A shallow copy shares nested data" expect="Delhi">
{`const account = { address: { city: "Pune" } };

</CodeRunner>

<CodeRunner title="Fix: A shallow copy shares nested data" expect="Pune">
{`const account = { address: { city: "Pune" } };
const edited = { ...account, address: { ...account.address } };
edited.address.city = "Delhi";
console.log(account.address.city);`}
</CodeRunner>

### Inherited names pass a naive membership test

Run the reproduction, then the corrected version. Compare the value at the boundary; the fix changes the cause rather than hiding the symptom.

<CodeRunner title="Bug: Inherited names pass a naive membership test" expect="true">
{`const actions = { save: true };

console.log(accepted);`}
</CodeRunner>

<CodeRunner title="Fix: Inherited names pass a naive membership test" expect="false">
{`const actions = { save: true };
const accepted = Object.hasOwn(actions, "toString");
console.log(accepted);`}
</CodeRunner>

## Takeaways

- Check the value that crosses the boundary before choosing the syntax.
- Map object keys use identity and Set removes duplicate values.
- Use stable ID strings when records should merge.
