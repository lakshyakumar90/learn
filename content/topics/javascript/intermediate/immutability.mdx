### Build the working version

<CodeRunner title="Build: Immutability and copying" expect="old 1\nnew 3\nnew root true\nshared address true\ncontract true">
{`const initial = {
  items: [{ id: "tea", quantity: 1 }],
  address: { city: "Pune" },
};
function updateCart(cart, id, quantity) {
  return {
    ...cart,
    items: cart.items.map((item) => {
      return item.id === id ? { ...item, quantity } : item;
    }),
  };
}
const changed = updateCart(initial, "tea", 3);
console.log("old", initial.items[0].quantity);
console.log("new", changed.items[0].quantity);
console.log("new root", changed !== initial);
console.log("shared address", changed.address === initial.address);
const contractChecks = [
  initial.items[0].quantity === 1,
  changed.items[0].quantity === 3,
];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}
</CodeRunner>

## Why it works this way

Deep-cloning every edit wastes work. Structural sharing is safe only when later writers respect the same ownership contract.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>
