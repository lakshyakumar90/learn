### Find its limit

A detached method loses its receiver. Change the input and predict the output before you run it. The failure comes from a specific default, lifetime or ownership assumption; keep that assumption visible in the test.

### Build the working version

<CodeRunner title="Build: Prototypes and the prototype chain" expect="tea\ninherits enabled true\nowns enabled false\nshared method true\nmap lives on prototype true\ncontract true">
{`const pluginBase = {
  enabled: true,
  run(input) {
    return input.trim();
  },
};
function makePlugin(name) {
  const plugin = Object.create(pluginBase);
  plugin.name = name;
  return plugin;
}
const searchPlugin = makePlugin("search");
const importPlugin = makePlugin("import");
console.log(searchPlugin.run(" tea "));
console.log("inherits enabled", searchPlugin.enabled);
console.log("owns enabled", Object.hasOwn(searchPlugin, "enabled"));
console.log("shared method", searchPlugin.run === importPlugin.run);
console.log("map lives on prototype", Object.hasOwn(Array.prototype, "map"));
const contractChecks = [
  Object.getPrototypeOf(searchPlugin) === pluginBase,
  !Object.hasOwn(searchPlugin, "run"),
];
if (!contractChecks.every(Boolean)) {
  throw new Error("The boundary contract was broken");
}
console.log("contract", contractChecks.every(Boolean));`}
</CodeRunner>

The console runner is an isolated browser worker. These core examples are also checked in Node; DOM behavior belongs to the browser frame, and fakeFetch is sample data rather than a real network request.

## Why it works this way

Do not edit built-in prototypes. Prefer composition when plugin capabilities vary independently instead of forcing deep inheritance.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>

## Takeaways

- Check the value that crosses the boundary before choosing the syntax.
- Lookup checks own properties before the prototype chain.
- Do not edit built-in prototypes.
