## How it works

<Diagram id="js-module-graph" />

ESM declares imports and exports; CommonJS uses require and module.exports. Bundlers follow a module graph to transform dependencies for a target.

## Why it works this way

The runner executes injected client logic, not imports. File examples show real syntax; extensions, package exports and interop need host integration tests.

<ConceptCard variant="under-hood">
Keep the operation's contract separate from its implementation. A faster path is useful only when it preserves the same outputs, error behavior and ownership rules; validate those boundaries before relying on a host-specific optimization.
</ConceptCard>

## Takeaways

- Check the value that crosses the boundary before choosing the syntax.
- ESM declares imports and exports; CommonJS uses require and module.exports.
- The runner executes injected client logic, not imports.
